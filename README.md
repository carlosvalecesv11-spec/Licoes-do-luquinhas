# Lições do Luquinhas

Canal de histórias animadas com lição de vida e plot twist.

- `identidade/`: foto de perfil, logo, modelo de capa e ficha do canal
- `episodios/`: vídeos prontos, roteiros e o código que gera cada vídeo

Para gerar um vídeo de novo: dentro da pasta do episódio, rode `python3 -m http.server 8765` e depois `node lrender.js` (precisa de Playwright e ffmpeg).
